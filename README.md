
# 実践で学ぶ人工知能

本リポジトリでは，書籍
『実践で学ぶ人工知能 ― 数値・言語・画像で理解する機械学習の基礎 ―』
（植木 一也 著，近代科学社Digital，2026年）のサンプルプログラムを公開しています．

Pythonを用いた実践的な演習を通して，AIや機械学習の基礎を段階的に学ぶことができます．機械学習の基本から，自然言語処理，大規模言語モデル，深層学習による画像認識，マルチモーダルAIまで幅広く扱い，プログラムを動かしながら実践的な理解を深められる構成になっています．
